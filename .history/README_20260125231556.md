## 🛠️ Quick Start

### Setup Locale
```bash
# Clona il repo
git clone https://github.com/darioschi-dev/ds-devfolio.git
cd ds-devfolio

# Installa dipendenze
npm install

# Avvia dev server
npm run dev
```
Apri [http://localhost:3000](http://localhost:3000) nel browser.

### Deploy
```bash
# Build per production
npm run build

# Deploy nel cluster
# (Segui le istruzioni in .github/.copilot-instructions.md)
scp -r .next/ user@cluster-node:/srv/ds-devfolio/
npm start  # Su cluster node
```

## 🌐 Dominio Personalizzato

Per collegare il dominio `darioschiavano.com`:

1. DNS punta al cluster personale (Raspberry Pi / Node)
2. Nginx/Caddy reverse proxy verso Next.js
3. SSL/TLS via Let's Encrypt

Dettagli di configurazione in `.github/.copilot-instructions.md`
